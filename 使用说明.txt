Ctrl+C 雷霆大C  —— 复制成功的视觉反馈
=========================================

【干嘛用的】
每次按 Ctrl+C，在你正在复制的那个文字光标位置，炸出一个炫彩的大 "C"，
然后自己消失。就是为了让你一眼确认"这次复制到底成没成"，不用再提心吊胆。


【怎么用】
1. 双击 CtrlCFlash.exe
2. 右下角托盘出现一个彩色 C 的图标，说明它已经在后台待着了
3. 随便找段文字选中，按 Ctrl+C，看效果

不需要安装，不需要 Python，删掉 exe 就等于卸载
（但记得先去设置里取消"开机自动启动"）。


【托盘图标怎么点】
· 左键单击 —— 预览一次动画
· 右键单击 —— 菜单：启用/暂停、预览、设置、开机自启、退出
· 双击     —— 打开设置窗口


【设置里能调什么】
外观页
  炫彩样式    彩虹流光 / 北极极光 / 霓虹果冻 / 烈焰熔岩 / 鎏金 /
              冰霜 / 糖果粉 / 矩阵绿 / 赛博紫电 / 自定义双色渐变
  自定义两色  直接点色块选颜色（点了会自动切到自定义渐变）
  流光速度    渐变色在字母上流动的快慢，0 就是完全静止
  字体        任意系统字体
  字重        常规 / 加粗 / 特粗
  起始大小    C 出现那一刻的尺寸（px）
  最大大小    C 放大到的最终尺寸（px）
  不透明度    10% ~ 100%
  辉光强度    C 周围的光晕厚度，0 就是关掉

动画页
  出现方式    缩放冲入 / 旋转飞入 / 淡入浮现 / 闪烁登场 / 弹性弹跳 / 雷霆砸落
  消失方式    淡出消失 / 放大消散 / 缩小消失 / 旋转飞出 / 闪烁熄灭 / 上飘消散
  三段时长    出现时长 / 停留时长 / 消失时长，可以精细到毫秒
  快捷风格    轻盈 / 标准 / 夸张，一键配好整套节奏
  额外效果    出现时带一圈向外扩散的光晕

其它页
  语言        简体中文 / English，选完整个界面当场变，不用重启
              （第一次运行会自动跟随系统语言）
  启用复制特效 / 优先定位到文字光标 / 开机自动启动 / 打开配置文件夹

所有改动都是即时生效的，改完直接按 Ctrl+C 就能看到，不用点保存。


【关于内存占用】
程序刚启动的一分钟里约占 50MB 内存（Qt 界面库本身的开销），
之后只要没有在复制，它会自己把内存还给系统，任务管理器里能看到降到 10MB 以内；
下次复制时会自动换回来，不会影响效果。
设置窗口是用完就关的：打开才创建，关掉就释放，不在后台常驻。


【配置文件】
%APPDATA%\CtrlCFlash\config.json
在设置窗口"其他"页有一键打开按钮。删掉这个文件就恢复出厂设置。


【常见问题】

Q: 右下角看不到它的图标？
A: Windows 11 默认把新出现的托盘图标收进隐藏区。点时间左边那个 ^（向上箭头）
   就能看到彩色的 C，用鼠标把它拖到任务栏上，以后就常驻显示了。

Q: 按了 Ctrl+C 没反应？
A: 1) 检查托盘菜单里"启用复制特效"是否勾着（被我暂停了就不会显示）。
   2) 某些安全软件会拦截全局键盘钩子，需要给它加白名单。
   3) 权限要对等：如果你在"以管理员身份运行"的程序里复制，
      本工具也得用管理员身份启动才能收到按键。

Q: C 出现的位置不在光标处？
A: 浏览器、VS Code 这类程序不一定向系统报告文字光标位置。
   设置 → 其他 → 关掉"优先定位到文字光标"，就会改成跟随鼠标位置。
   程序拿不到光标时也会自动退回鼠标位置，不会不显示。

Q: 动画太挡视线了？
A: 动画页点"轻盈"，或者把"停留时长"调到 0、把"最大大小"调小一点。

Q: 想用英文界面？
A: 设置 → 其它 → 语言 → English，整个界面（包括托盘右键菜单、提示气泡）
   立刻切成英文；切回简体中文同样在这里。设置会记住你的选择。

Q: 想换个触发键？
A: 目前固定是 Ctrl+C（Alt+Ctrl+C 不会触发）。

Q: 开机会自启吗？
A: 默认不。右键托盘 → 开机自动启动，勾上就行。
   如果你把 exe 挪了地方，下次启动它会自动把自启路径更新成新位置。
